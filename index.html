Paso 1 · Configurar Playoff en Vercel

Esto se hace una sola vez, y lo haces tú: las credenciales no pasan por el chat. En Vercel, en el proyecto rollerfun-panel → Settings → Environment Variables, añade estas cuatro:

  1. PLAYOFF_HOST — tu dominio de Playoff, sin https://. Ejemplo: rollerfun.playoffinformatica.com
  2. PLAYOFF_USER — el usuario que te dio Playoff para la API
  3. PLAYOFF_PASS — su contraseña
  4. PANEL_CLAVE — una clave que inventas tú, para que este panel no lo abra cualquiera

Marca las cuatro para Production. Después vuelve aquí y dale a Comprobar.
